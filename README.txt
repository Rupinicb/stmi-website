STMI starter website
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to preview in a browser.
4. Edit index.html to change text and contact details.
5. Edit style.css to change colours and layout.

This is a static starter site. It does not collect student data or accept payments.
Before publishing, verify all programme details, legal status, refund terms and contact information.
The site clearly identifies STMI as a private training initiative and makes no accreditation or job guarantee claims.
